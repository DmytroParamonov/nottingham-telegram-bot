# 🏰 Шериф Ноттінгема — Telegram Bot

Фанатська Telegram-реалізація гри про торгівлю, декларування, контрабанду, хабарі та шерифа. Проєкт не використовує офіційні ілюстрації чи повний текст правил і не є офіційним продуктом правовласників настільної гри.

Інтерфейс бота — **українською мовою**. Термінологія орієнтується на українську локалізацію Games7Days другої редакції: **дозволені товари, контрабанда, хабар, прилавок, Торгівля, Завантаження товарів, Декларування, Огляд**.

## Поточний режим

Зараз реалізовано **стандартну гру для 3–5 гравців** за базовими правилами 2-го видання.

Шостий гравець навмисно поки не допускається: у другій редакції для шістьох використовуються **два заступники шерифа**, тайл здобичі та окремі правила огляду. Робити шістьох із одним звичайним шерифом було б неправильно.

## Що вже працює

- 3–5 гравців у груповому чаті;
- кожен отримує 50 золотих і 6 карток;
- окрема колода для гри втрьох: усі картки з позначкою `4+` вилучаються;
- у грі втрьох кожен стає шерифом 3 рази;
- у грі вчотирьох або вп’ятьох — 2 рази;
- випадковий перший шериф;
- **Крок 1 — Торгівля:** торговці можуть скинути 0–5 карток і добрати до 6;
- скинуті під час Торгівлі картки публічно показуються в групі;
- шериф під час Торгівлі руку не змінює;
- **Крок 2 — Завантаження товарів:** у мішок кладеться 1–5 карток;
- після запечатування змінити мішок неможливо;
- **Крок 3 — Декларування:** починає гравець ліворуч від шерифа, далі по колу;
- кількість карток декларується точно;
- можна назвати лише один вид дозволеного товару;
- декларація фіксується ботом і публікується в групі — змінити її потім неможливо;
- **Крок 4 — Огляд:** шериф може оглянути будь-яку кількість мішків у будь-якому порядку або не оглядати жодного;
- грошові хабарі;
- шериф може окремо **прийняти хабар і пропустити** або **проігнорувати хабар і пропустити безкоштовно**;
- якщо чесного торговця оглянули — шериф платить штраф за всі картки в мішку;
- якщо торговець збрехав — задекларовані товари потрапляють на його прилавок, а всі інші товари конфіскуються й штрафуються;
- якщо золота не вистачає, борг покривається товарами з прилавка: спочатку дозволеними, потім контрабандою;
- при проході без огляду дозволені товари стають відкритими, а вид контрабанди залишається таємним; публічно видно лише її кількість;
- наприкінці раунду всі добирають руку до 6 карток;
- автоматичне перемішування скидання, якщо колода закінчилася;
- фінальний рахунок: золото + вартість товарів + бонуси «короля» і «королеви»;
- правильний поділ бонусів при нічиїй з округленням донизу;
- тай-брейки: спочатку кількість дозволених товарів, потім кількість контрабанди;
- SQLite — окремий сервер бази даних не потрібен.

## Важливі цифрові адаптації

Деякі фізичні дії адаптовані під Telegram, не змінюючи основну економіку гри:

1. **Перший шериф обирається випадково.** У настільних правилах ним стає гравець із найбільшою кількістю готівки при собі, що для Telegram не має сенсу.
2. **Торгівля технічно проходить паралельно.** Порядок визначається тим, хто раніше підтвердив обмін. Скинуті картки все одно відкриті для всіх, а картки поточного кроку не повертаються в колоду до завершення Торгівлі.
3. **Сплата боргу товарами автоматизована.** У настільній грі боржник сам обирає конкретні картки. Бот підбирає комбінацію з мінімальною переплатою, дотримуючись обов’язкового порядку: спершу дозволені товари, потім контрабанда.
4. **Поки автоматизовані лише хабарі золотом.** Хабарі товарами, товарами з мішка, домовленості щодо чужих мішків і майбутні послуги будуть окремим модулем переговорів.

## Чого ще немає

- хабарів товарами з прилавка;
- хабарів товарами з мішка з можливістю блефувати про їх наявність;
- хабарів від третіх гравців за огляд чужого мішка;
- угод, обов’язкових у поточному раунді, та необов’язкових майбутніх обіцянок;
- режиму 6 гравців із двома заступниками;
- королівських товарів;
- чорного ринку;
- опціонального таймера на Огляд;
- режиму 7 карток на руці;
- вилучення 10 випадкових карток на початку партії.

Ці модулі краще додавати після стабільного тесту базової партії 3–5 гравців.

- Python 3.11+

## Швидкий запуск

```bash
git clone https://github.com/DmytroParamonov/nottingham-telegram-bot.git
cd nottingham-telegram-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
python main.py
```

`.env`:

```env
BOT_TOKEN=токен_від_BotFather
DATABASE_PATH=data/nottingham.sqlite3
```

## Як грати

1. Кожен гравець відкриває бота в особистому чаті та натискає `/start`.
2. Додайте бота до спільного Telegram-чату.
3. Творець партії пише `/newgame`.
4. Інші пишуть `/join`.
5. Творець запускає гру через `/begin`.
6. Торговці проходять `/market`.
7. Після завершення Торгівлі збирають `/bag` і запечатують мішки.
8. Бот по черзі викликає торговців на Декларування.
9. Після всіх декларацій починається Огляд: можна вести переговори та пропонувати `/bribe 5`.
10. Шериф відкриває `/inspect` і вирішує долю кожного мішка.
11. Після останнього раунду бот автоматично рахує підсумок.

## Команди

### У групі

- `/newgame` — створити лобі
- `/join` — приєднатися
- `/leave` — вийти з лобі
- `/players` — список гравців
- `/begin` — почати партію
- `/status` — стан партії
- `/cancelgame` — скасувати активну партію

### В особистому чаті

- `/start` — меню
- `/market` — Торгівля
- `/hand` — рука
- `/bag` — мішок
- `/bribe 5` — запропонувати 5 золотих
- `/inspect` — панель поточного шерифа
- `/status` — стан партії

## Raspberry Pi / systemd

Приклад `/etc/systemd/system/nottingham-bot.service`:

```ini
[Unit]
Description=Nottingham Telegram Bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi/nottingham-telegram-bot
ExecStart=/home/pi/nottingham-telegram-bot/.venv/bin/python /home/pi/nottingham-telegram-bot/main.py
Restart=always
RestartSec=3
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now nottingham-bot
sudo systemctl status nottingham-bot
```

Якщо користувач Raspberry Pi має інше ім’я, заміни `User=pi` та шляхи.
