# 🏰 Шериф Ноттінгема — Telegram Bot

Фанатська Telegram-реалізація гри про торгівлю, блеф, контрабанду, хабарі та шерифа.

Інтерфейс гри — **українською мовою**. Проєкт не використовує офіційні ілюстрації чи повний текст правил і не є офіційним продуктом правовласників настільної гри.

## 🎮 Головна ідея UX

Бот тепер працює за принципом **button-first**: команди залишаються як запасний шлях, але звичайна партія проходиться кнопками.

У групі є спільний **Ігровий стіл**:

- поточний раунд;
- етап гри;
- шериф;
- хто зараз торгує або декларує;
- золото кожного;
- публічна частина прилавків;
- кнопка **🎮 МОЯ ПАНЕЛЬ**.

У приватному чаті кожен отримує власну фазову панель. Бот показує тільки ті дії, які зараз дозволені правилами:

- 🛒 хід у Торгівлі;
- 🎒 складання мішка;
- 📜 декларацію;
- 👮 панель шерифа;
- 🤝 угоди та хабарі;
- 📦 руку;
- 📊 стан партії.

Тобто гравцеві не потрібно пам’ятати список команд і не можна випадково натиснути дію не з того етапу.

## ✅ Поточний режим

Реалізована стандартна базова гра для **3–5 гравців**.

Шостий гравець навмисно поки не допускається: у другій редакції для шістьох використовуються два заступники шерифа та окремі правила огляду.

## 🧩 Що вже працює

- 3–5 гравців;
- 50 золотих на старті;
- рука з 6 карток;
- окрема урізана колода для гри втрьох;
- у грі втрьох кожен стає шерифом 3 рази;
- у грі вчотирьох або вп’ятьох — 2 рази;
- випадковий перший шериф;
- правильна послідовність етапів;
- шериф обирає першого торговця;
- Торгівля йде по колу;
- відкритий скид 0–5 карток;
- добір руки до 6;
- мішок 1–5 карток;
- після запечатування мішок не змінюється;
- послідовне декларування зліва від шерифа;
- декларація фіксується та не редагується;
- можна декларувати лише один вид дозволеного товару;
- шериф може оглянути будь-яку кількість мішків або не оглядати жодного;
- правильні штрафи чесному й нечесному торговцю;
- конфіскація неправильно задекларованих товарів;
- оплата боргів товарами, якщо не вистачає золота;
- контрабанда після проходу без огляду залишається долілиць;
- публічний інтерфейс не показує вид прихованої контрабанди;
- автоматичний добір руки в кінці раунду;
- автоматичне перемішування скиду при порожній колоді;
- фінальний рахунок;
- бонуси короля й королеви;
- правильний поділ бонусів при нічиїй;
- тай-брейки за кількістю дозволених товарів і контрабанди;
- SQLite без окремого сервера БД.

## 🤝 Угоди та хабарі

Під час етапу **Огляд** працює окремий конструктор формальних угод.

Гравець може запропонувати шерифу:

- 💰 золото;
- 🏪 товари зі свого прилавка;
- 🎒 товари зі свого мішка за пропуск власного мішка;
- 🔍 оплату за огляд чужого мішка;
- 📌 обов’язковий додатковий огляд іншого гравця в цьому ж раунді;
- 💭 майбутню необов’язкову обіцянку.

Обіцяними товарами дозволено блефувати. Якщо гравець пообіцяв товар, якого насправді немає, бот передасть тільки фактично наявну частину та публічно зафіксує, що решта була блефом.

Карти з руки використовувати в угоді не можна.

Прийнята поточна угода виконується ботом одразу, щоб шериф не міг узяти хабар і порушити обов’язкову частину домовленості наступним натисканням кнопки.

## 🏰 Як почати партію

1. Кожен гравець відкриває бота в особистому чаті та натискає `/start`.
2. Додайте бота до спільної Telegram-групи.
3. У групі натисніть `/start`.
4. Натисніть **🎲 Створити партію**.
5. Інші гравці натискають **➕ Приєднатися**.
6. Творець натискає **🚀 ПОЧАТИ ГРУ**.
7. Далі користуйтеся кнопкою **🎮 МОЯ ПАНЕЛЬ** та підказками бота.

Команди `/newgame`, `/join`, `/begin`, `/market`, `/bag`, `/deal`, `/inspect` залишаються доступними для сумісності та налагодження.

## 🚀 Запуск

```bash
git clone https://github.com/DmytroParamonov/nottingham-telegram-bot.git
cd nottingham-telegram-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
python main.py
```

`.env`:

```env
BOT_TOKEN=токен_від_BotFather
DATABASE_PATH=data/nottingham.sqlite3
```

## 🧪 Тести

```bash
python -m compileall -q .
python -m pytest -q
```

CI автоматично запускається на GitHub Actions після кожного push у `main`.

## 🥧 Raspberry Pi / systemd

Приклад `/etc/systemd/system/nottingham-bot.service`:

```ini
[Unit]
Description=Nottingham Telegram Bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi/nottingham-telegram-bot
ExecStart=/home/pi/nottingham-telegram-bot/.venv/bin/python /home/pi/nottingham-telegram-bot/main.py
Restart=always
RestartSec=3
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now nottingham-bot
sudo systemctl status nottingham-bot
```

Якщо користувач Raspberry Pi має інше ім’я, заміни `User=pi` та шляхи.
