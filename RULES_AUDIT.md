# Аудит правил — Sheriff of Nottingham: 2nd Edition

Цей файл тимчасово фіксує напрямок розробки бота. Основний README містить актуальну реалізацію.

- Базовий режим: 3–5 гравців.
- 3 гравці: вилучаються картки 4+, кожен стає шерифом 3 рази.
- 4–5 гравців: кожен стає шерифом 2 рази.
- 6 гравців потребують окремого режиму двох заступників.
- Кроки: Торгівля → Завантаження товарів → Декларування → Огляд → Кінець раунду.
- Декларація фіксується й не змінюється після подання.
- Шериф може проігнорувати хабар і пропустити торговця безкоштовно.
- Якщо бракує золота на штраф, борг покривається спочатку дозволеними товарами, потім контрабандою.
- Види успішно провезеної контрабанди залишаються таємними до кінця гри.
